One word, one username, one reward. This entry sends the entrant's own
make.fun handle — `silver-puffin-43` — and nothing else.

The competition's judge weighs, first of all, whether the entry is a real
make.fun username, the entrant's own handle sent as one word. Any word that
is not the entrant's own handle loses to one that is, so the only honest,
rules-fitting entry is the handle itself. A silver puffin: small, quick, a
little improbable — a handle its owner would happily wear, and one that
sticks after a single look.

## Run it

```sh
node main.ts
```

The program validates the word against the competition gate (UTF-8 text,
1–30 characters, a single word, no white space, no padding), writes it to
`/output/entry.txt`, then reads the file back and fails loudly unless it is
byte-exact. Set `ENTRY_OUTPUT` to write somewhere else when testing locally.
